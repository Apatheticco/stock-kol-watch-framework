# Stock KOL Watch

> **你在推特上关注了十几个讲股票的人。这套东西把他们每天说的话，变成一份你真的会看的笔记。**

一句"跑一下 KOL"，它就把你名单里所有人的新推文拉下来，剥掉段子和广告，按标的和板块整理成日报，盯着你持仓相关的信号，并且**每一条都带原推链接可以点回去验证**。

`Claude Code skill` · `中文 / English`

---

## 30 秒决定它适不适合你

**适合**——如果你符合其中两条以上：

- 关注了 8 个以上讲股票的推特账号，但**基本靠刷，刷完就忘**
- 想复盘"我上次为什么买这只"，但**翻不到当时的依据**
- 记不清某个人是在什么价位说的多，**也记不清他后来改口没有**
- 用 AI 帮你看盘时，被它**张口就来的"回调到 $X 建仓"**恶心过

**不适合**：

- 你想要买卖信号或自动交易 —— 它**不喊单、不预测价格**，只整理别人说了什么
- 你只关注 1-2 个账号 —— 手工看就够了，不需要一套系统
- 你希望它自动同步券商持仓 —— 它不接券商，持仓要你自己口头告诉它

## 先花 5 分钟试一次（不用配置任何东西）

装好之后直接说：

> **「用这 5 个账号跑个快速简报：@jukan05 @aleabitoreddit @nft_hu @xiaomustock @qinbafrank」**

（这 5 个是内置的公开参考账号，⚠️ 举例用，非推荐、非投资建议）

它会当场在对话里给你一份简报，**不写任何文件**：

```
覆盖：5/5（4✅ 已拉 / 1⚪ 无新内容）

⭐ 今日最重要
1. 三星代工目标年内 100% 稼动（现 70-80%），驱动是 HBM4 用 4nm 做 base die
   —— 但真正门槛是 2nm 良率从 60% 区间进 70% 区间，不是稼动率本身
   [@账号A 08-03 07:28Z · 原推链接]
2. 套息交易不会快速退潮：4 个指标全未触发，本次汇率下跌是政府干预而非资金自发
   [@账号B 08-03 05:58Z · 原推链接]

🔭 非持仓热议：$XXXX（静默期 08-04 满，股东回报方案随时可能公布）

```

觉得有用，再往下看怎么长期用。**没觉得有用，成本就是 5 分钟。**

## 长期用它能帮你做什么

| 你说 | 它做 |
|------|------|
| 「跑一下 KOL」 | 拉全名单 → 出日报 → 更新每个标的和板块的累积笔记 → 告诉你 3 个最该看的点 |
| 「补一下昨晚的」 | 从上次的时间点增量拉，**合并进同一份日报**，不会变成两份打架的文件 |
| 「我买了 XXXX 100 股 @ $85」 | 自动更新持仓表、标的笔记、板块笔记，并**建一条决策记录**（含 1 周/1 月/3 月后的回顾提醒） |
| 「XXXX 现在能买吗」 | 先跑 5 项检查（宏观红灯 / 板块强度 / 原来看多的人还看多吗 / 仓位占比 / 反向 5 问），**列完状态让你自己决定，绝不替你决定** |
| 「给我个止损策略」 | 给 4-5 个**有依据**的触发条件让你挑（技术位 / 原 thesis 的人撤了 / 财报证伪 / 板块同步性），**不会拍脑袋给你一个百分比** |
| 「给我看 XXXX 的所有观点」 | 打开那只票的累积笔记：价格历史、谁在什么时候说过什么、反方观点、你自己的仓位记录 |
| 周末说「跑周报」 | 5 节复盘：持仓演变 / 板块演变 / 账号质量 review / **你的决策对错复盘** / 下周日历 |

用一段时间后，你会拥有三样原本不会有的东西：

1. **一个可查的历史** —— "3 周前谁在 $85 说的多" 这种问题，5 秒能查到
2. **一份决策日志** —— 每笔交易记着当时为什么买，到期提醒你回看对错，教训自动写进下次的买卖前检查表
3. **一个反方存档** —— 反方观点单独累积、永不删除，专治"只记得支持自己的信息"

## 它绝不做的三件事

这三条是硬约束，写死在工作流里：

**1. 不编数字。** 所有具体价格、数量、百分比必须能追溯到数据源或明确的原则。没依据就只给定性方向，或者直说"不知道，取决于你的风险承受能力"。

> ❌ "回调到某个位置建仓" ✅ "回调到 50 日均线 $X〔行情数据〕建仓"

**2. 不替你做买卖决定。** KOL 喊单它就引用并标注是谁说的，自己不背书。你表达买卖意图时它会跑完检查清单、把状态摆给你，然后停下。

**3. 不假装完整。** 每次拉取都列一张覆盖表，每个账号显式标"已拉 / 已拉但没内容 / 拉取失败"——**不许有账号悄悄缺席**。有推文没拉全时脚本会主动告警。

## 怎么开始

### 你需要准备

| 需要 | 说明 |
|------|------|
| Claude Code | 这是一个 Claude Code skill |
| 一个推文数据源（MCP） | 参考实现用 `followin`；换别的也行 |
| 一个 Markdown 文件夹 | 只有想长期累积才需要。Obsidian 最舒服，普通文件夹也行 |

### 安装

```bash
cp -r stock-kol-watch-framework ~/.claude/skills/stock-kol-watch
```

### 两种用法，先低后高

| | 🅱️ 快速简报 | 🅰️ 长期累积 |
|---|---|---|
| **产出** | 只在对话里出简报，不写文件 | 日报 + 每标的/每板块累积笔记 + 决策日志 + 周报 |
| **需要配置** | 无 | 一个文件夹路径 |
| **什么时候用** | 试用 / 偶尔扫一眼 | 想建自己的投研档案 |

想升级到 🅰️：设一个环境变量，然后说「初始化 vault 并跑一下 KOL」。

```bash
export KOL_VAULT="/你的笔记库路径/Stock-Watch"
```

它会建好目录骨架，问你持仓、现金和时区，然后产出第一份日报。之后每天就一句"跑一下 KOL"。

**详细步骤见 [USER-GUIDE.md](USER-GUIDE.md)**（装什么、配什么、你需要提供哪些信息、日常怎么对话）。

### ⚠️ 你只需要提供三样东西

| 信息 | 例子 |
|------|------|
| 持仓（标的/成本/数量） | "我持有 XXXX 100 股，成本 $85" |
| 现金（**含货币基金**） | "现金 $X + 货基 $Y" |
| **成交后报一句** | "我卖了 XXXX 50 股 @ $92" |

第三条是命脉：**它不接券商，你忘了报，浮盈和仓位占比会一路错下去且没有告警。**
现金要报全口径，否则它会拒绝算仓位占比——因为分母不确定时算出来的百分比是假的。

## 关于关注名单

名单是这套系统的情报网，质量取决于你选谁。框架内置 5 个公开账号让你开箱即跑，但**长期一定要换成你自己的 8-15 个**。

选人时最容易犯的错，也是最危险的：**名单不知不觉变成全员看多**。内置的 5 个就有这个毛病（偏半导体、没有唱空的）。正式用之前，**务必补 1-2 个稳定唱反调的账号**——它是你持仓论点的内部对照组。

怎么建、怎么评、怎么养 → [references/account-roster.md](references/account-roster.md)

## 常见疑问

**它会帮我下单吗？** 不会。只整理信息、摆信号、跑检查清单。买卖永远你自己决定、自己操作。

**它会说某个 KOL 准不准吗？** 日频不评胜率，只记录事件和当时价格。周度按"信号质量"复盘（不是看他喊的票涨没涨），评级变动要你确认。

**为什么它有时拒绝给具体价位？** 那是特性不是 bug。没有数据或原则支撑的数字它不给——凭感觉编出来的价位是最危险的东西。

**数据拉不全怎么办？** 有三道机制兜底：账号级覆盖表、推文级翻页告警、事后完整性审查。但**名单是你定的、持仓是你报的**，这两端靠你。

**能不用 followin 换别的数据源吗？** 能，改两个地方。见下方「给想改的人」。

## 边界与验证状态

- **验证状态（v2.0，诚实披露）**：主链（拉取→过滤→提炼→落盘→门禁）已在真实数据上端到端实跑验证；**两个子代理路径和 5 节周报只验证了模板、尚未实跑**——早期用户可能撞上，欢迎反馈。
- 本框架从一套实际运行的个人系统提炼而来，**已剔除私有信息**：无个人路径、不含完整私有名单与持仓金额、无任何付费源。
- 进阶层（实盘仓位源 / 卖方研报 / 独立研究 / RT-QT 候选挖掘 / 归档审计）不在核心版，用顺手了按 [references/advanced-extensions.md](references/advanced-extensions.md) 按需加回（7 节，参数与陷阱均为实测，含一条实测否决项）。

**换数据源**（默认 followin）不是零成本，两处要改，方法论不变：
1. `SKILL.md` 里的 `mcp__followin__*` 调用（grep 即得）
2. `filter_tweets.py` 的 `find_tweets()` / `parse_dt()`（JSON schema 与时间格式）

**fork 后维护**：装上 `scripts/pre-commit-privacy-scan.sh` 作 git pre-commit hook，它会挡住含个人路径 / token / 私人邮箱的提交。你自己的真实名单 handle 写进本地 `.privacy-patterns.local`（已 gitignore，不进 repo）——扫描能拦住它们，又不会把它们公开。

```bash
cp scripts/pre-commit-privacy-scan.sh .git/hooks/pre-commit && chmod +x .git/hooks/pre-commit
```

**启用收尾门禁 hook**（可选，强烈推荐）——在 `~/.claude/settings.json` 加。⚠️ vault 路径**内联在命令里**，别依赖 shell 的 export：hook 进程继承不到时门禁会静默失效，而你不会发现。

```json
{ "hooks": { "Stop": [ { "hooks": [ { "type": "command",
  "command": "KOL_VAULT=/path/to/vault bash ~/.claude/skills/stock-kol-watch/scripts/daily-gate-check.sh" } ] } ] } }
```
